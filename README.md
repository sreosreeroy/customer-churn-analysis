# Customer Churn Analysis
Customer Churn Analysis using Python, SQL, and Power BI to identify factors influencing customer churn and retention.
## Project Overview
This project analyzes customer data to understand churn patterns and identify factors associated with customer retention and attrition. The analysis was performed using Python, SQL, and Power BI to explore customer characteristics, services, contracts, tenure, charges, and revenue.
## Objective
- Analyze customer data to identify factors associated with churn.
- Examine customer demographics, services, contracts, tenure, and charges.
- Identify patterns among customers who churned and those who remained.
- Use Python, SQL, and Power BI to generate meaningful business insights.
- Present the findings through an interactive Power BI dashboard.
  ## Tools & Technologies
  - Python (Pandas, Numpy, Matplotlib, Seaborn)
  - Jupyter Notebook
  - SQL
  - Power BI
  - Github
 ## Data Preparation & Analysis
 The customer churn dataset was cleaned and prepared in Jupyter Notebook using Python, data quality, missing values, data types, and relevant customer fields were reviewed before performing the analysis. The cleaned dataset was then used for SQL analysis and Power BI visualization.
 ## SQL Analysis
 SQL was used to analyze the cleaned customer churn data and examine customer behavior and churn patterns. The analysis covers customer counts, churn, charges, revenue, contracts, services and other factors associated with customer retention.
 ## Power BI Dashboard
 An interactive Power BI dashboard was created to analyze customer churn patterns and present key customer churn metrics.
The dashboard includes key performance indicators and visualizations covering customer demographics, senior citizen status, services, contracts, tenure, monthly charges, revenue, and churn patterns.
## Key Business Insights
- Churn patterns can vary across different customer characteristics and service categories.
- Contract type and customer tenure provide useful context when analyzing churn behavior.
- Monthly charges and revenue can be compared across churned and retained customers.
- Customer service and subscription characteristics can help identify differences in churn patterns.
- the analysis provides a consolidated view of customer churn using Python, SQL, and Power BI.
